# prorack.ai

Static website for ProRack AI, presenting a connected digital project layer around ProRack's warehouse engineering workflow.

## Preview

Run any static server from the repository root, for example:

```bash
python3 -m http.server 4600
```

## Deploy

Netlify publishes the repository root using `netlify.toml`.

## Content scope

The site uses the user's supplied ProRack introduction: requirement capture, system design, structural verification, change control, connected engineering outputs and project visibility. It avoids customer endorsements, project-specific information and unverified AI performance claims.
